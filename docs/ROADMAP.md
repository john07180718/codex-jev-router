# Roadmap

下列未勾選內容是未完成工作，不是目前已存在的功能。

## v0.1 起始包

- [x] 短版全域規則與按需 Skill
- [x] 受限的 Choice / Score / Noul HTTP 客戶端
- [x] Mock / Off / Live，明確的專案授權
- [x] 本機共享任務額度、每日額度、超時、有限重試
- [x] 資料最小化規則、常見敏感字串阻擋、結構驗證
- [x] 同任務重複抑制、不持久保存原始 prompt/response
- [x] 備份與保留原全域規則的安裝／移除
- [x] 合成範例、離線測試、GitHub CI 設定與用量比較工具

## 發佈前的真實驗收

- [ ] 使用自己有效帳號，以合成資料進行真實 API smoke test
- [ ] Windows / WSL / macOS / Linux 的實際安裝驗證
- [ ] GitHub CI 測試矩陣實際成功紀錄
- [ ] Codex 對正例／反例任務的 Skill 自動選用測試
- [ ] 不同專案規則與工作目錄的載入驗證
- [ ] 獨立安全檢視；目前不是已完成安全稽核的產品
- [ ] 多個配對任務、品質不退步的真實 benchmark

## 後續可評估

- [ ] 工具端候選片段蒐集器：明確 allowlist、排除敏感檔、只送必要片段
- [ ] 針對各任務的標註資料、錯誤分析與適用條件
- [ ] 使用官方公開穩定的 Codex usage 介面；不可猜測私人檔格式
- [ ] Plugin 分發與必要時 MCP 封裝
- [ ] 跨機器共用且有真正權限邊界的 budget service
- [ ] 具期限與明確資料政策的答案快取
- [ ] 可核驗定價與計費資訊後的美元預算

不規劃默認自動部署、自動交易、付款或刪資料權限。這些必須是獨立產品需求。
