## Optional JEV development assistance
Use `jev-assist` only for bounded semantic triage, candidate relevance, or a narrowly scoped diff check when it can avoid substantial reading/reasoning. Prefer code, search, and tests for deterministic work. Check local readiness before preparing payloads. Respect project opt-outs and external-data authorization; never enable live mode, authorize data, raise budgets, or integrate JEV into products without the user's explicit instruction. JEV is advisory, never approval. Unavailable means continue with existing safe tools. Do not claim token savings without comparable measurements.
